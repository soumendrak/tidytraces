# October 22 animated illustrations

The latest published edition on `origin/master` at the start of this change was
`2026-10-22` (base commit `19fdd327035435c50166811378dbf230292e435c`).
Its six stories now have animated explainers. Article text, original publication
evidence, research, scores, original WebPs and their provenance remain unchanged.
Earlier editions are unchanged.

Each GIF has four readable stages, a 12.6-second loop, moving records or explicit
state changes, and holds for reading. The evaluation graphic shows label and
refusal as alternative branches. These are conceptual editorial diagrams, with
source limitations preserved in their labels.

Total GIF payload: **1,663,331 bytes**. Every asset is 1000 × 800 pixels and
under 300,000 bytes. Sharp/cgif uses 80 colors, no dithering, changed-pixel
transparency and duplicate-frame coalescing. There are no new dependencies.

The edition keeps `image` as the reviewed static WebP and adds `image_animation`
for the browser enhancement. The `<picture>` source selects GIFs only on screens
with no reduced-motion preference, after controls initialize. Each image has a
keyboard-accessible pause/play button. Pausing shows the complete original
static diagram. Reduced motion, print/PDF, JavaScript-disabled reading and failed
GIF requests use static fallbacks. The zoom view follows the selected image and
live motion preference. Social previews and Markdown keep the static diagram;
JSON includes the animation metadata and final hashes.

## Generation and review evidence

All six original image files were inspected before editing. One built-in
imagegen edit per story produced four source-grounded illustration vignettes.
The complete prompts are in [the generation record](2026-10-22-generation.json)
and the edition's animation provenance. No image API fallback was used.

`scripts/animate-edition-2026-10-22.mjs` typesets the final labels and composes the
mechanism animation. Run it with a directory containing the reviewed four-cell
PNG strips named after the six story slugs. The original generated PNGs are kept
in local run evidence at `.cache/edition-animation/art/`, with their SHA-256
hashes in the edition data. This is a one-off compositor for this edition.

All decoded GIF frames and the four held stages were inspected for readable
labels, arrow direction, source scope, transition artifacts and loop resets.
Local contact sheets are `.cache/edition-animation/*-all-frames.png` and
`*-decoded-stages.png`. Production browser captures are under
`.cache/edition-animation/production-browser/` at 1440, 390 and 320 pixel
viewport widths. They cover all six illustrations, plus homepage views.

The browser regression reuses the existing presentation test's build and checks
GIF selection, pause/resume, zoom, live reduced-motion changes, print, readable
no-JS fallbacks, aborted GIF requests and a historical edition. The asset test
fully decodes every frame and verifies budgets, timing, looping, distinct
states, dimensions, SHA-256 hashes and original static fallbacks.

Final local verification: `npm test` passed all 38 tests; `npm run check`
reported zero errors, warnings or hints; `npm run build` produced all 13 static
pages and all ten edition PDFs. Logs are in `.cache/edition-animation/`.

The requested GIF exception is confined to this edition's enhancement. Daily
curation, its static WebP validation, general editorial policy, publishing
schedule and deployment configuration are unchanged.
