# Newspaper fonts

Unmodified WOFF2 files served by Google Fonts for Lora (variable weights 400-700) and PT Serif (400 and 700), normal and italic. Latin and Latin Extended subsets are bundled locally so newspaper rendering does not depend on a font CDN.

The SIL Open Font License notices are included as lora-OFL.txt and ptserif-OFL.txt. manifest.json records each original download URL and SHA-256. newspaper.css preserves the served font-face declarations, replacing only remote source URLs with local filenames.
